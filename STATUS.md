## Sandbox setup

No sandbox needed beyond the `shared/` submodule sync, which `start-thread`
already runs automatically.

**Building a slide deck** needs its own dependencies: `cd slides && npm install`
once per machine or sandbox, then `npm run all` to build and check. They are
not the guide builder's and are not shared with it.

Building a guide to PDF works in a fresh sandbox. **Do not put emoji in
anything that becomes a PDF** — the sandbox has no emoji font and bakes a
placeholder box into the file, which is what happened to the robotics
worksheet's `🤖`. Geometric characters like `☐` and `◇` are fine and are
what the checkoff sheets use. If an unusual character is in a file, render
the page and look at it rather than warning about it:

```
pdftoppm -png -r 80 -f 1 -l 1 FILE.pdf /tmp/x
```

then copy the PNG somewhere readable and open it. That is how the Unit 02
sheet was confirmed before deploying on 2026-08-20.

## Class 01 — the welcome deck

**`Engineering _ Class 01 _ Welcome (2026).pptx`, 20 slides, rebuilt from the
old 31-slide deck on 2026-08-26.** The original is still in the repo root under
its own name; nothing was overwritten.

The deck's job is not only to welcome. **It is a filter.** Guidance places
students here who belong in the other Engineering class at Natick — the one
where a student can sit on a phone, hand in an arts-and-crafts project late,
and take an A. Ray's goal is that all of them switch out, in the first period,
of their own accord. That is why the first project is electronics and the
second is software engineering: a student who does not find this kind of work
fun should discover it on day one.

The design consequence, worth keeping: **a filter built on "this class is
hard" selects on confidence, not interest** — the anxious student who would
thrive leaves and the coaster stays. So the deck shows the work instead
(what you will have built by December, "engineering is fun / engineering is
not easy") and then makes the exit explicit, warm and unashamed. The old deck
had that exit as a throwaway line at the bottom of the phone slide.

Structure is **hook → the honest deal → how it works → start**, so the rules
and grading land after the choice rather than interrupting the pitch. Palette
is charcoal, off-white and amber, dark slides for title, sections and close.

## Unit 02 — Software Engineering

not software program management.** [DECISIONS #19](DECISIONS.md). This is
Level 4 AI-assisted development: the AI writes all the code, humans write
the prompt and check the result, and reading or writing code is not a goal
of this unit at any project. Verification throughout is behavioral only —
run it, check it against the prompt, never open the code.
[DECISIONS #29](DECISIONS.md). Guides live in `guides/unit02/`, named
`pNN.md` (Unit 01 owns `eNN`), with their own `course.js` and `deploy.txt`.
