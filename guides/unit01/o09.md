Ollama is the AI software engineer for your Simon game. You tell it what you built. It writes the Arduino code.

You do not have to read the code. You have two jobs: describe your circuit clearly, and check that the code does what you asked.

# Step 1: Open Ollama and pick the model

Press **Command-Space**, type "Ollama", and press Return.

At the bottom of the window is the model pulldown. Click it and choose `qwen2.5-coder:7b`. Do this every time you open the app.

![[o09_model.png]]

# Step 2: Ask for the hardware test first

Fill in the pins from your Tinkercad circuit. The AI only knows what you tell it.

```
Write an Arduino Uno sketch. It is a hardware test.
LEDs: red pin __, green pin __, blue pin __, yellow pin __.
Buttons use pull-down resistors, so a pin reads HIGH when
pressed: red pin __, green pin __, blue pin __, yellow pin __.
Speaker on pin __.
LCD: 16x2 I2C, address 0x27, SDA on A4, SCL on A5.
When I press a button, its LED lights and the speaker plays
a tone. The LCD shows "Testing...".
Use the LCD library the same way as this example:
```

Under it, paste the LCD HelloWorld sketch from Project 08. Then press Return.

# Step 3: Copy the code

Wait for Ollama to finish. A half-written block can look finished.

Skip any block labeled **bash**. Find the code block. It may be labeled **cpp** or **arduino**. Click **Copy** in its upper right corner.

# Step 4: Run it in Tinkercad

Open your circuit. Click **Code**, and switch it to **Text**. Select all the old code, paste over it, and click **Start Simulation**.

# Step 5: Fix what goes wrong

**It does not compile.** Copy the red error text. Paste it into the same chat and add: "This did not compile. Please fix it." Paste the new code over the old and run again. You do not need to understand the error.

**It runs but does the wrong thing.** Check your wiring against the Project 09 checklist first. A wrong wire looks exactly like wrong code. Then tell Ollama what you saw in one sentence: "When I press the red button, the blue LED lights."

# Step 6: Ask for the game

When the hardware test works, ask for the game in the same chat:

```
The hardware test works. Now write the full Simon game for
the same pins. The LCD gives instructions and shows the
score. Each color plays its own tone.
```

Test it the same way. Play it and check it against the Project 09 requirements.

# Step 7: Run it for real

In the Arduino IDE, choose **File > New Sketch**. Select everything, paste your working code, and click the **Upload** arrow. Errors go back to Ollama, as in Step 5.

# If Ollama gets slow

The AI re-reads the whole chat every time, so a long chat gets slow. Start a new chat, paste your working code and pins, and say what you still need.
